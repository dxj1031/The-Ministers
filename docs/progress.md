## 目的 1：消解迎合感 · 已完成

**做法**：迎合不再是一条看不见的公式，而是一个看得见、将来可以罢免的角色。

| 步 | 内容 | commit |
| --- | --- | --- |
| 1 | `sycophancy_rate` 指标 + `--lean` 对照跑法 + 监控台两列 | `040ff3a` |
| 2 | 第十二位大臣「应声」，`lean` 撤出辩论引擎 | `4c8075a` |
| 3 | 裁决双句：判词由应声念，谏言引用终局反对方原话 | `5030486` |

**量出来的东西**：原以为污染来自倒戈阈值里的 `lean` 项，撤掉后迎合率一动不动。
真正的藏身处是强制站队那一行（`"pro" if lean >= 0 else "con"`），值 +2.6pp；
而且 `>= 0` 让 `lean=0` 也算赞成，连「中立」那条基线本身都是偏的。
第三处在回合 prompt 里（`皇帝倾向 lean=…`）—— 票型测不到，但十一张嘴都在顺着皇帝说话，
它是靠「`lean` 只能有一个消费者」这条约束逐行查出来的，不是靠指标发现的。

**门禁**：`test_lean_does_not_reach_debaters()` —— 把随机种子钉死，
三个 `lean` 必须跑出逐条相同的立场序列。离线基线 48.0% / 48.0% / 48.0% 是佐证，不是门禁
（倒戈种子里掺了 `uuid4`，换个 checkout 绝对值会飘）。

**还留着的尾巴**：
- 名册页和演示朝堂还是十一位 —— 一个只在裁决时开口的角色，摆进名册需要自己的出场方式
- M1.4 罢免应声（`decree(kind="dismiss")`）：朝堂少一个声音，但没有人再顺着你

## 目的 2：揣测用户状态 · 机制完成

**做法**：用户状态不是一句话里读出来的，是攒出来的，所以交给档案官拾荒（🦝 浣熊）持续追踪。

| 步 | 内容 | commit |
| --- | --- | --- |
| 1 | `user_read` 追加表，按字段取最新 | `be1627b` |
| 2 | 拾荒整理多轮输入（奏章 + 历次圣旨 + 此前议题），定向投喂五位 | `ee67fe7` |
| 3 | 桌面右栏「朕的心事」四项可改，用户改过的由代码钉死 | `58b1cac` |

**真机输出**（三十岁读博）：`anxiety` 失去稳定收入和结婚机会 · `impulse` 立刻去读博 ·
`stake` 职业发展与家庭期望 · `deadline` 三十五岁。

**没做的**（设计文档里已标明）：
- **机械层指标**：`user_read_fields`（抽出几项）、`user_read_churn`（相邻两次整理的字段变化率）。
  churn 是这条机制真正的风险指标 —— 每次把四个字段推倒重来的档案官等于没在追踪，
  只是在反复猜，它应当随输入增多而下降。**这个我能做，优先级最高。**
- **语义层指标** `user_read_accept_rate`：要七个冻结 case 的人工参考答案。
  **得由产品的人来标** —— 顺手编出来的基线只会证明模型和我想的一样，不会证明它说中了用户。

## 目的 3：第三方视角 · 进行中

**做法**：裁决之后不是一句判词，而是一面镜子：这次是哪几种偏见把你推过去的、
你忽略了谁、以及你的裁决是不是早在提交奏章之前就定了。

**已完成**：
- `court_session` 加 `lean_open` / `verdict_aligned` 两列，老库由 `store.LATE_COLUMNS` 补
- `lean_open` 只在 `create_session` 写一次，没有 setter —— 事后问拿到的是合理化，不是数据
- `_aligned()` 三种值：开场没倾向记 `NULL`（不是 0，否则把没表态的局当证据拉低确认率）；
  带着倾向却搁置或退朝记 0 —— 那正是「这次没被自己的倾向牵着走」
- `_mirror()`：推你过去的三位、你忽略的那位、跨局确认率，全部从 `turn` 表算，不调模型。
  「你忽略的」直接复用谏言（`_remonstrance`）—— 同一个判据算两遍迟早算出两个答案
- 奏章屏一个原生 `<input type="range">`（三档读数：偏驳回／尚无定见／偏准奏），开堂那一下送出去
- 裁决屏「🪞 朝堂镜」三行；这一屏改成可滚动（内容 890px > 容器 725px，原本会裁掉）

**没做**：
- M3.3 御笔批注进 `turn` 表（`kind="note"`），「你总是收藏维斯帕」这类跨局模式才算得出来

**验收**：确认率本身就是指标。长期稳定在 100% 说明产品是一台盖章机 ——
这个数字不需要优化到某个值，它需要被用户看见。
